BẢN TÍCH HỢP 11LABS.ID.VN CHO BOOM REVIEW
Ngày: 29/09/2026

Cài bản vá:
1. Thoát BOOM Review.
2. Giải nén ZIP vào thư mục mã nguồn, chọn ghi đè file cũ.
3. Build/chạy lại ứng dụng.

Sử dụng:
1. Tại phần Giọng đọc, nhập API key dạng PL_... vào ô "API key 11LABS VN".
2. Chọn Nguồn = "11LABS VN", rồi bấm "Tải giọng 11LABS VN".
3. Danh sách giọng chỉ hiện tên ngắn; chọn "Nguyệt Nga Podcast" hoặc giọng mong muốn.
4. Chạy Full Pipeline như bình thường. Script Editor và pipeline đều dùng đúng provider đã chọn.

Danh sách được lọc theo Nguồn:
- Miễn phí / Offline: chỉ hiện Edge TTS và Piper.
- 11LABS VN: chỉ hiện giọng tải từ API 11labs.id.vn.
- Pekka: chỉ hiện giọng Pekka.
- Voice ID được giữ ngầm, không hiển thị trên giao diện.

An toàn và tự động:
- API key được mã hóa trong cấu hình của máy, không ghi cứng trong mã nguồn/ZIP.
- Job ID được lưu để tiếp tục poll/tải nếu mạng gián đoạn; không tự POST lại một job chưa rõ kết quả.
- Hỗ trợ MP3/WAV, tốc độ 0.7x-1.7x và văn bản tối đa 10.000 ký tự mỗi request.
- Đã thử thực tế 3 job đồng thời với giọng Nguyệt Nga: 3/3 thành công.
- File kiểm tra đa luồng: scripts/probe_elevenlabs_vn_parallel.py (chỉ chạy thủ công vì có tốn quota).

Ngưỡng bám cảnh tự động:
- Pipeline vẫn sửa các lỗi bám cảnh theo từng block trước khi tạo voice.
- Nếu chỉ còn tối đa 3 block và không quá 10% tổng số block, hệ thống ghi cảnh báo rồi tiếp tục TTS.
- Lỗi diện rộng trên 10%, câu lặp, lời kể lỗi/rỗng hoặc thiếu nội dung quá nhiều vẫn dừng an toàn.
- Cảnh báo nhỏ đã chấp nhận được khóa theo chữ ký kịch bản; retry voice không chạy lại sửa bám cảnh từ đầu.

Lưu ý:
- Đây là API của 11labs.id.vn, không phải API ElevenLabs chính thức.
- Mỗi khách nên dùng API key riêng. Không gửi key cá nhân kèm bản ZIP.
- Nếu HTTP 429/503, giảm tải và thử lại; adapter không tự đổi sang giọng/provider khác.
